# Table 表格

> 展示和处理结构化数据的核心组件，是 B 端系统中使用频率最高、最复杂的数据展示组件。

---

## 1. 何时使用

### 适用场景

✅ **数据列表** - 展示多条结构化数据（用户列表、订单列表等）
✅ **数据比较** - 并排对比多个数据项的属性
✅ **数据操作** - 需要对数据进行排序、筛选、编辑
✅ **数据详情** - 展示单个对象的详细属性（描述列表形式）
✅ **复杂表单** - 表格形式的批量数据录入
✅ **报表展示** - 统计报表、财务数据等

### 不要使用的场景

❌ **少于 3 列数据** - 应使用 List 组件
❌ **非结构化数据** - 应使用卡片或自定义布局
❌ **简单的键值对** - 应使用 Descriptions 组件
❌ **时间序列数据** - 应考虑 Timeline 组件
❌ **层级关系为主** - 应使用 Tree 组件

### 替代方案

| 场景 | 推荐组件 | 说明 |
|------|---------|------|
| 简单列表 | `List` | 灵活的列表容器，适合卡片式展示 |
| 描述列表 | `Descriptions` | 展示单个对象的属性 |
| 树形数据 | `Tree` | 层级关系为主的数据 |
| 时间轴 | `Timeline` | 时序事件展示 |
| 卡片网格 | `Card` + `Grid` | 图文混合的数据展示 |

```
│  标题 / 工具栏 (可选)                            [操作]  │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌──┬────────┬────────┬────────┬────────┬────────┐    │
│  │☐│ 姓名    │ 年龄 ▼│ 部门    │ 状态    │ 操作   │    │ ← 表头 (Header)
│  ├──┼────────┼────────┼────────┼────────┼────────┤    │
│  │☑│ 张三    │ 28     │ 技术部  │ 在职 ●  │ 编辑   │    │ ← 表体行 (Body Row)
│  ├──┼────────┼────────┼────────┼────────┼────────┤    │
│  │☐│ 李四    │ 32     │ 产品部  │ 离职 ●  │ 编辑   │    │
```

### 2.2 元素说明

| 元素 | 名称 | 必需 | 说明 |
|------|------|------|------|
| **Container** | 表格容器 | ✅ | 包含所有元素，定义边框和阴影 |
| **Header** | 表头 | ✅ | 列标题、排序、筛选控件 |
| **Body** | 表体 | ✅ | 数据行 |
| **Row** | 行 | ✅ | 单条数据记录 |
| **Cell** | 单元格 | ✅ | 单个数据值 |
| **Fixed Column** | 固定列 | ⚪ 可选 | 左侧或右侧固定的列 |
| **Selection Column** | 选择列 | ⚪ 可选 | 复选框列 |
| **Expand Icon** | 展开图标 | ⚪ 可选 | 展开/收起子表格或详情 |
| **Sort Icon** | 排序图标 | ⚪ 可选 | 升序/降序指示器 |
| **Filter Icon** | 筛选图标 | ⚪ 可选 | 筛选条件设置 |
| **Empty State** | 空状态 | ⚪ 可选 | 无数据时的占位内容 |
| **Loading** | 加载状态 | ⚪ 可选 | 数据加载中的骨架屏或 Spin |
| **Footer** | 表尾 | ⚪ 可选 | 分页、统计信息 |
| **Summary Row** | 汇总行 | ⚪ 可选 | 合计、小计等 |

### 2.3 表头结构（Header）

```
┌──┬──────────┬──────────┬──────────┬──────────┐
│☐│ 姓名      │ 年龄 ▼   │ 部门 🔽  │ 操作     │
│  │          │          │          │          │
└──┴──────────┴──────────┴──────────┴──────────┘
   ↑           ↑          ↑
```

**表头单元格包含：**
- 列标题文字
- 排序图标（▲ 升序 / ▼ 降序）
- 筛选图标（🔽）
- Tooltip（如果标题过长）
- Resize 手柄（可调整列宽）

## 3. 尺寸与间距

### 3.1 三种尺寸规格

| 尺寸 | 行高 | 单元格垂直内边距 | 单元格水平内边距 | 字号 | 使用场景 |
|------|------|-----------------|----------------|------|---------|
| **Large** | `56px` | `16px` | `16px` | `14px` | 数据较少、需要舒适阅读 |
| **Middle** | `48px` | `12px` | `16px` | `14px` | 默认尺寸，最常用 |
| **Small** | `40px` | `8px` | `12px` | `14px` | 数据密集、需要紧凑展示 |

**B 端推荐：**
- 默认使用 **Middle** (48px)
- 数据 > 20 行时使用 **Small** (40px)
- 详情页/强调数据时使用 **Large** (56px)

### 3.2 表头尺寸

| 尺寸 | 表头高度 | 垂直内边距 | 水平内边距 | 字重 |
|------|---------|-----------|-----------|------|
| Large | `56px` | `16px` | `16px` | `600 SemiBold` |
| Middle | `48px` | `12px` | `16px` | `600 SemiBold` |
| Small | `40px` | `8px` | `12px` | `600 SemiBold` |

### 3.3 列宽规范

#### 默认列宽

| 列类型 | 宽度 | 说明 |
|--------|------|------|
| 选择列 | `48px` | 复选框列（固定宽度） |
| 展开列 | `48px` | 展开图标列（固定宽度） |
| 序号列 | `60px` | 行号列 |
| 操作列 | `120px - 200px` | 根据按钮数量调整 |
| 状态列 | `80px - 120px` | 标签/徽标 |
| 日期列 | `160px` | 日期时间（YYYY-MM-DD HH:mm） |
| 姓名列 | `120px` | 人名 |
| 邮箱列 | `200px` | 邮箱地址 |
| 文本列 | `160px - 240px` | 一般文本 |

#### 最小列宽

```
最小列宽 = 48px（保证可点击区域）
```

#### 列宽分配策略

```
固定列（如操作列）: 固定宽度（120px）
内容列:           自适应 / 百分比
                 auto / 20% / 1fr

总宽度不足时:      按比例缩小（但不小于最小列宽）
总宽度超出时:      出现横向滚动条
```

### 3.4 间距规范（基于 4px 网格）

#### 单元格内边距

```
Large:
┌─ 16px ─┬──────────┬─ 16px ─┐
│        │  内容    │        │  56px 高
└────────┴──────────┴────────┘

Middle:
┌─ 16px ─┬──────────┬─ 16px ─┐
│        │  内容    │        │  48px 高
└────────┴──────────┴────────┘

Small:
┌─ 12px ─┬──────────┬─ 12px ─┐
│        │  内容    │        │  40px 高
└────────┴──────────┴────────┘
```

**Token 映射：**
- Large 水平: `spacing-4` (16px)，垂直: `spacing-4` (16px)
- Middle 水平: `spacing-4` (16px)，垂直: `spacing-3` (12px)
- Small 水平: `spacing-3` (12px)，垂直: `spacing-2` (8px)

#### 表格外边距

```
表格与上方元素间距: 16px (spacing-4)
表格与下方元素间距: 16px (spacing-4)
```

#### 固定列阴影

```
左侧固定列右边缘: 4px 阴影
右侧固定列左边缘: 4px 阴影

box-shadow: 4px 0 8px -2px rgba(0, 0, 0, 0.08);
```

### 3.5 表格高度

#### 无限高度（默认）

```
表格高度 = 表头 + 所有行 + 分页
自适应内容
```

#### 固定高度（虚拟滚动）

```
表格高度 = 600px（固定）
表头固定在顶部
表体内部滚动
```

**推荐固定高度场景：**
- 数据 > 100 行
- 需要固定表头
- 页面高度受限

#### 最大高度

```
max-height: 800px
超出后表体滚动
```

## 5. 组件状态（States）

### 5.1 表格状态

| 状态 | 触发条件 | 视觉变化 | 说明 |
|------|---------|---------|------|
| **Empty** | 无数据 | 显示空状态占位 | 提供操作引导 |
| **Loading** | 数据加载中 | 显示骨架屏或 Spin | 首次加载 |
| **Refreshing** | 刷新数据 | 顶部显示加载条 | 后续刷新 |
| **Error** | 加载失败 | 显示错误提示 + 重试按钮 | 网络错误等 |
| **Scrolling** | 用户滚动 | 固定表头、固定列阴影 | 提供方向感 |
| **Filtering** | 应用筛选 | 筛选图标变蓝 | 显示已筛选状态 |
| **Sorted** | 已排序 | 排序图标高亮 | 显示排序方向 |
| **Selecting** | 选中行 | 行背景变蓝 | 显示选中数量 |

### 5.2 行状态（Row States）

| 状态 | 视觉变化 | 优先级 |
|------|---------|--------|
| **Default** | 白色背景 | 最低 |
| **Hover** | 灰色背景 (#FAFAFA) | 低 |
| **Selected** | 蓝色背景 (#E3F2FD) | 高 |
| **Disabled** | 灰色文字 + 禁用光标 | 最高 |
| **Expanded** | 显示子行（缩进） | - |
| **Editing** | 单元格变为输入框 | - |

**状态优先级：**
```
Disabled > Selected > Hover > Default
```

### 5.3 单元格状态（Cell States）

| 状态 | 视觉变化 | 使用场景 |
|------|---------|---------|
| **Default** | 正常文字 | - |
| **Hover** | 显示 Tooltip（文字过长） | - |
| **Editable** | 虚线边框（可选） | 可编辑表格 |
| **Editing** | 输入框 + 蓝色边框 | 编辑中 |

### 7.2 表格类型变体

#### 基础表格

```
- 简单数据展示
- 无交互功能
- 适合静态报表
```

#### 可选择表格

```
- 带复选框/单选框
- 支持批量操作
- 适合数据管理
```

#### 可排序表格

```
- 列头可点击排序
- 显示排序图标
- 适合数据分析
```

#### 可筛选表格

```
- 列头带筛选菜单
- 显示筛选图标
- 适合数据查询
```

#### 可展开表格

```
- 行可展开显示详情
- 支持树形结构
- 适合层级数据
```

#### 可编辑表格

```
- 单元格可编辑
- 行内保存/取消
- 适合批量录入
```

#### 虚拟滚动表格

```
- 固定高度
- 虚拟渲染
- 适合大数据（10000+ 行）
```

## 10. 设计最佳实践

### 10.1 Do's（推荐做法）

#### ✅ 合理的列宽分配

```
✅ 正确：
│ 姓名(120px) │ 邮箱(200px)        │ 部门(100px) │ 操作(120px) │

❌ 错误：
│ 姓名(400px)         │ 邮箱(100px) │ 部门(100px) │ 操作(50px) │
```

#### ✅ 清晰的操作列

```
✅ 正确：
│ 操作           │
│ 编辑 删除      │ ← 文字按钮，间距 8px

❌ 错误：
│ 操作           │
│ 编辑删除复制   │ ← 按钮过多，无间距
```

#### ✅ 合理的分页

```
✅ 正确：
- 默认每页 20 条（B 端常用）
- 提供 10/20/50/100 选项
- 显示总条数

❌ 错误：
- 每页 5 条（过少）
- 每页 500 条（过多，性能差）
```

#### ✅ 数据对齐

```
✅ 正确：
│ 姓名     │ 金额      │ 操作   │
│ 张三     │  ¥100.00 │ 编辑   │ ← 文字左对齐
│ 李四     │ ¥1,000.00│ 删除   │    数字右对齐
```

### 10.2 Don'ts（不推荐做法）

#### ❌ 过多的列

```
❌ 错误：表格有 15+ 列
✅ 正确：
- 最多 8-10 列（桌面端）
- 超过 10 列考虑固定列或列选择器
- 移动端最多 3-4 列
```

#### ❌ 文字截断不明显

```
❌ 错误：
│ 这是一段很长的... │ ← 用户不知道完整内容

✅ 正确：
│ 这是一段很长的... │ ← 悬停显示 Tooltip
  ↓
┌────────────────────┐
│ 这是一段很长的描述 │ ← Tooltip 显示完整文本
└────────────────────┘
```

#### ❌ 筛选和排序不明显

```
❌ 错误：
│ 姓名 │ 年龄 │ ← 无图标，用户不知道可以排序/筛选

✅ 正确：
│ 姓名 🔽│ 年龄 ⇅│ ← 清晰的图标提示
```
