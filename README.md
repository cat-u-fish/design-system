# 设计规范

## 目录结构

```
/design-system
  /foundations        # 基础定义层
    /tokens          # Design Token（色彩、字体、间距等最小单位）
    /assets          # 基础资源（图标、插画、图片等视觉资产）
  /components         # 组合构建层（组件库、模板库）
  /patterns           # 行为交互层（状态、动效、交互模式）
  /content            # 内容表达层（文案、信息架构）
  /platforms          # 应用场景（移动端、Web端、桌面端等）
  /governance         # 治理维度（命名规则、版本管理、使用规范）
```
